## ScholarFlow v1.2.0

### Features

#### Multiple Update Sources
- **GitHub**: Official source for users with VPN
- **GitHub Mirror**: Accelerated via gh-proxy.com, recommended for China users
- Switch update source in Settings page

#### Version Comparison
- Fixed version comparison logic
- Show current version in "already latest" message

#### Auto Configuration
- Mirror mode auto-fetches latest release tag
- Fallback to GitHub source on failure

### Improvements
- Dynamic version display
- Developer mode disabled in production
- Optimized update UI

### Bug Fixes
- Fixed version not refreshing after update
- Fixed version comparison logic error
